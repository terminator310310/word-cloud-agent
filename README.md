# 热榜词云 · Hot Word Cloud

大一学生项目：不写一行"设计"，全程用中文给 AI 编程智能体（opencode）提需求，
30 分钟搭出一个每天稳定出图的热点聚合工具。

**它做什么**
- 每天自动抓取百度/头条/知乎/B站公开热榜标题（免登录、低频、不碰任何私密内容）
- 中文分词 + 停用词过滤 → 按板块生成词云图，词越大 = 讨论越多
- 缓存 7 天数据自动汇总周报大图：10 秒看完全周热点

**为什么做**：刷 50 条热搜两小时记不住，看 1 张词云 10 秒就够了。

> 合规声明：仅对公开榜单标题做词频统计，不转载、不存储任何文章正文与个人信息。
